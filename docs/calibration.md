# 转速标定指南

## 为什么要标定

`fan_map` 决定「滑块百分比 → PWM 占空比」。不同调压模块、不同输入电压、不同风扇的起转阈值和线性度都不一样，**同一个占空比对应的输出电压完全不同**。换任一环节都必须重新标定。

## 测量前提（先排掉三个假象）

1. **必须带载**：空载时输出端电容会被斩波脉冲充到接近 Vin，万用表直流档读的是峰值，任何占空比 >0 都像满压。
2. **先验固件**：量 GPIO 对 GND 的直流平均电压（3.3V 逻辑：10%→0.33V、50%→1.65V、100%→3.3V）。这组对上了，才说明固件输出正确，问题在模块侧。
3. **别用并联电容"滤波"**：纯电容 + 开关是峰值检波，会让任何占空比都全速。要平均电压必须串电感（buck）并加续流二极管（阴极接开关节点、阳极接 GND）。

## 标定步骤

### 第一步：让滑块百分比直通占空比

临时把 `fan_map` 改成：

```cpp
id(pwm_out).set_level(constrain(state, 0.0f, 1.0f));
```

烧写后，滑块 40% 就是占空比 40%。

### 第二步：带载测量 3~5 个点

记录「占空比 → 风扇两端电压」，例如本项目实测（12V 输入、双 MOS 模块）：

| 占空比 | 输出电压 |
|---|---|
| 40% | 4.75V |
| 50% | 5.78V |
| 80% | 9.50V |

### 第三步：定目标端点

用户需求通常是端点电压，例如「1% 对应 4.75V，100% 对应 9.5V」。1% 的含义是「可靠起转且风可感」，允许它直接跳到 40% 占空比——起转阈值以下没有意义。

### 第四步：反解占空比并写成线性映射

若测得 `Vout ≈ 占空比 × Vin`（带电感/同步整流的模块基本如此）：

```
duty_low  = V_low  / Vin      // 4.75 / 12 ≈ 0.396 → 取 0.40
duty_high = V_high / Vin      // 9.50 / 12 ≈ 0.792 → 取 0.80
```

代码：

```cpp
float s = constrain(state, 0.0f, 1.0f);
float duty;
if (s <= 0.001f) {
  duty = 0.0f;                                  // 0% 必须真关断
} else {
  duty = duty_low + (s - 0.01f) * (duty_high - duty_low) / 0.99f;
}
id(pwm_out).set_level(constrain(duty, 0.0f, 1.0f));
```

非线性时（低段陡、高段缓）就取多个锚点做分段线性插值，把实测点写进注释。

## 验证

1. 滑块 1% → 目标低压（风扇起转）
2. 滑块 50% → 中间值应落在两端中点附近
3. 滑块 100% → 目标高压
4. 滑块 0% → 输出 0V（MOS 完全关断）

偏差超过 0.3V 说明中间段非线性，补一个实测锚点即可。
